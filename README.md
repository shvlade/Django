# Фрагменты Django-блога

> Учебные фрагменты Django-блога: формы поиска и комментариев, представления и начальная миграция.

**Стек:** Python · Django

## Что сохранено

Формы поиска и комментариев, фрагменты представлений блога и начальная миграция.

## Статус

Текущая версия содержит только часть Django-проекта: нет `manage.py`, полного набора настроек, моделей и шаблонов; `views.py` заканчивается незавершённым определением функции. Самостоятельный запуск этой версии невозможен.

Более полный учебный блог находится в [Django2](https://github.com/shvlade/Django2).
